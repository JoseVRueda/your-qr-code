Preguntas frecuentes

¿Es gratis?

Sí. Puedes crear y descargar el código sin cuenta y sin pago.

¿Se guarda lo que escribo?

No. El código se genera en tu navegador. Nada se envía a un servidor ni se guarda.

¿Qué puedo codificar?

Un enlace, un texto, una red Wi-Fi, un correo o un teléfono.

¿Qué es la corrección de errores?

Es lo que permite leer el código aunque se tape o se dañe una parte. L cabe más texto; H aguanta más daño y el código queda más denso.

¿Por qué importa el contraste?

El lector distingue los módulos oscuros del fondo claro. Si los colores se parecen, el código puede no leerse.
